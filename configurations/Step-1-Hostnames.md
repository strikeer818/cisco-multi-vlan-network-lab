# Step 1 - Device Hostnames

## Objective

Configure hostnames on all network devices to make the topology easier to identify and manage.

## Router-CORE

```cisco
enable
configure terminal
hostname Router-CORE
end
```

## Router-BRANCH

```cisco
enable
configure terminal
hostname Router-BRANCH
end
```
